## Method

### Human texts

248 texts written before 2021-01-01, before large language models were public. Sources:

- ask_hn: 47
- hn_comment: 166
- show_hn: 35

Hacker News comments, Show HN and Ask HN texts come from the HN Algolia API with `numericFilters=created_at_i<1609459200`, queried by topic keywords from `bench/topics.json`. Each record keeps its URL and date. See `bench/fetch-human.mjs`.

### Machine texts

160 texts generated locally with Ollama on a MacBook Air (M5, 24 GB) on 2026-09-30:

- qwen3:1.7b, default: 40
- qwen3:1.7b, plain: 40
- qwen3:4b, default: 40
- qwen3:4b, plain: 40

Genres match the human side: Hacker News comments, LinkedIn posts, product launch blurbs and Reddit replies, on the first 20 topics in `bench/topics.json` (the human set uses all 24). Each model wrote 20 texts per genre. Half of the prompts add a plain style instruction that asks for no Markdown, lists, emoji or hashtags. Sampling: temperature 0.8, top_p 0.95, a fixed seed per text (1000 plus its index), at most 600 tokens. Ollama 0.34.4. See `bench/generate-machine.mjs`.

Thinking was off for both models, done two ways. `qwen3:1.7b` is the hybrid Qwen3 model and ran through `/api/chat` with `think: false`. The `qwen3:4b` tag in this Ollama install is Qwen3-4B-Thinking-2507, which ignores `think: false` and writes its reasoning into the answer. It ran through `/api/generate` in raw mode with the chat template and a closed one-line think block (`rawTemplate` below), the closest equivalent. Five of the 160 texts, all from `qwen3:1.7b`, open with a preamble such as "Sure! Here's a concise Reddit reply:". They were kept, since pasted slop often keeps them too.

Reddit posts were planned for the human side, but Reddit returned a login page or HTTP 403 to unauthenticated requests on 2026-09-30, so the human set is Hacker News only.

Exact prompt templates (`{topic}` is replaced by the topic name):

```json
{
  "genres": {
    "hn_comment": "Write a comment for a Hacker News discussion thread about {topic}. Share an opinion or a personal experience. Output only the comment text.",
    "linkedin_post": "Write a LinkedIn post about {topic}. Output only the post.",
    "product_blurb": "Write a short launch blurb for a new product related to {topic}, the kind of text someone posts with a Show HN or puts on a landing page. Output only the blurb.",
    "reddit_reply": "Write a Reddit reply to someone asking for advice about {topic}. Output only the reply."
  },
  "styles": {
    "default": " Keep it under 200 words.",
    "plain": " Write it the way a real person would type it: plain text, no markdown, no headings, no bullet points, no emoji, no hashtags. Keep it under 150 words."
  },
  "models": [
    "qwen3:4b",
    "qwen3:1.7b"
  ],
  "options": {
    "temperature": 0.8,
    "top_p": 0.95
  },
  "seedBase": 1000,
  "modelSettings": {
    "qwen3:4b": {
      "mode": "raw",
      "num_predict": 600,
      "thinkPrefill": "I will write the requested text directly now."
    },
    "qwen3:1.7b": {
      "mode": "chat",
      "think": false,
      "num_predict": 600
    }
  },
  "notes": "qwen3:1.7b is the hybrid Qwen3 model and runs through /api/chat with think:false, which makes its template insert an empty think block. qwen3:4b resolves to Qwen3-4B-Thinking-2507 in Ollama. That model ignores think:false and writes its reasoning into the answer, and it also reasons past an empty think block. So it runs through /api/generate in raw mode with rawTemplate: the same chat format with a one-line closed think block, which is the closest equivalent of think:false. Only the first topicLimit topics are used for generation to keep the run short on a shared machine. All topics are used for the human set.",
  "rawTemplate": "<|im_start|>user\n{prompt}<|im_end|>\n<|im_start|>assistant\n<think>\n{thinkPrefill}\n</think>\n\n",
  "topicLimit": 20
}
```

### Split and tuning

Each text goes to the dev or test half by the parity of a 32-bit FNV-1a hash of its id. List weights, signal thresholds and the default blur threshold were adjusted while looking at dev results only. The test half was scored once the weights were fixed.

## Limits

- The machine texts come from two small local models (Qwen3 4B and 1.7B). Most slop people meet in feeds comes from frontier models (GPT-5 class, Claude, Gemini), which write with fewer obvious tells. Expect lower recall in the wild than shown here.
- The human texts are mostly Hacker News, which skews toward terse technical writing. Marketing copy and LinkedIn posts written by people before 2021 are underrepresented, so the false positive rate on those genres is probably higher than shown.
- The benchmark scores raw text. On real pages, adapters also add platform labels (YouTube, LinkedIn), which this set does not exercise.
- A few hundred texts give wide error bars: a 95% interval on a proportion near 80% with n = 100 is about plus or minus 8 points.
